# ExcelSmartCost Add-in (C# VSTO Skeleton)

This folder contains C# skeleton files you can copy into a Visual Studio VSTO Add-in project.

- Ribbon.xml: Ribbon layout
- Ribbon1.cs: Button handlers (calls QuantityRecalc)
- EngineClient.cs: HTTP client to Python engine
- QuantityRecalc.cs: Batch read Calc_Expr and write Quantity back (multi-output TODO)
